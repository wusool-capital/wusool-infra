# User guide

This guide is the starting point for using the Wusool Capital platform. Choose
the task you want to complete; you do not need to understand the underlying
infrastructure.

| I want to… | Go to |
| --- | --- |
| Find and review buyer–seller matches | [Wusool Toolkit](toolkit.md#find-matches) |
| Add, edit, or research a buyer or seller | [Wusool Toolkit](toolkit.md#maintain-buyer-and-seller-records) |
| Record and transcribe a meeting | [WusoolScribe](scribe.md#record-and-transcribe-a-meeting) |
| Send a meeting note to the CRM | [WusoolScribe](scribe.md#send-a-meeting-to-attio) |
| Find or update a CRM record | [Attio CRM](attio.md) |
| Use a website valuation, readiness, benchmark, or buyer tool | [Website lead tools](lead-tools.md) |
| Open or use workflow automation | [n8n](n8n.md) |
| Resolve a problem or request support | [Troubleshooting and support](troubleshooting.md) |

## The products

| Product | Purpose | Where you use it |
| --- | --- | --- |
| **Wusool Toolkit** | Match buyers and sellers and maintain their profiles | Slack |
| **WusoolScribe** | Record, transcribe, summarize, and file meetings | Desktop app |
| **Attio** | View and manage the business CRM | Web browser or Attio app |
| **Website lead tools** | Give website visitors useful reports and capture their details | Wusool Capital website |
| **n8n** | Build and run internal workflow automations | Web browser |

Attio is the business-facing source of record. Toolkit changes are written to
Attio first and then copied to the Wusool database. Website leads and meeting
notes also arrive in Attio, so Attio is normally the best place to look for
the current business record.

{% hint style="info" %}
Access is managed separately for Slack, WusoolScribe, Attio, and n8n. If a
product is missing or rejects your login, ask your Wusool administrator rather
than creating a second account.
{% endhint %}
