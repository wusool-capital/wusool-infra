# User Guide

Two products are covered here:

| Product | What it's for | Where it runs |
| --- | --- | --- |
| **Wusool Toolkit** | Finding buyer–seller matches and editing buyer/seller profiles | A Slack bot — no separate website or login |
| **WusoolScribe** | Recording, transcribing, and summarizing meetings, and pushing the summary into the CRM | A desktop app on your computer |

Use the Toolkit whenever you need to search for a match or change a profile.
Use WusoolScribe whenever you're in a meeting you want a transcript and
summary of.
