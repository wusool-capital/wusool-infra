# Installing WusoolScribe

## Windows

1. Download the latest installer from the link your team provides.
2. Run the installer.

## macOS

1. Download the latest `.dmg` from the link your team provides.
2. Open the downloaded file.
3. Drag **WusoolScribe** to your Applications folder.
4. Open **WusoolScribe** from the Applications folder.

## First launch

The first time you open WusoolScribe, it downloads a local transcription
model. This is a one-time step; after that, transcription works fully
offline.

![The onboarding screen shown on first launch.](../../images/scribe-onboarding.png)

WusoolScribe automatically detects your computer's GPU (Apple Silicon,
NVIDIA, AMD/Intel) and uses it to speed up transcription — no configuration
needed. If no supported GPU is found, it falls back to CPU transcription.

## Updates

WusoolScribe checks for updates automatically. See
[Updates](updates.md) for how that works.
