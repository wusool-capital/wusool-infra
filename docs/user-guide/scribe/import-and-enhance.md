# Import & Enhance

{% hint style="info" %}
This feature is in Beta.
{% endhint %}

If you already have a recorded meeting as an audio file, you can import it
instead of recording live:

1. Choose **Import** and select an audio file.
2. WusoolScribe transcribes it locally, the same way as a live recording.

You can also **Enhance** a meeting you've already recorded — re-transcribe it
with a different model or language, without leaving your machine.
