# Deliverables

A running record of what shipped each delivery period, for the client and
their team to review without digging through commit history.

Each period covers a rolling 30 days, running the 12th/13th of one month
to the 12th of the next — matching the delivery/billing cycle, not the
calendar month. Every entry links back to [`CHANGELOG.md`](../../CHANGELOG.md)
for full technical detail; this section stays to the point — a couple of
lines per feature, fix, or improvement.
